# 2.3.0 release gates

The public source tree is available for review, but the stable `2.3.0` Release and Obsidian Community submission remain blocked until every item below has dated evidence.

- [x] Core, storage, authority, menu, migration-compatibility, package, privacy, and 34-page layout automation.
- [x] Store-v4 portable backup verification and candidate-only restore automation.
- [x] Core runs without the optional Apple companion in automated isolation.
- [ ] Real Obsidian 1.8.10 acceptance in a de-identified isolated Vault.
- [x] Real current-stable Obsidian 1.13.7 onboarding and window-reload acceptance in a de-identified isolated Vault (2026-08-29). See `CURRENT-STABLE-ACCEPTANCE.md`.
- [ ] De-identified real Obsidian screenshots for light/dark and desktop/mobile-width documentation. One dark desktop screenshot is present; light and physical mobile evidence remain pending.
- [ ] Physical iPhone initialization, basic editing, menu viewing, restart, and offline recovery.
- [ ] Seven consecutive days with separately recorded desktop, iPhone, offline, and restore results.

Any serious data-loss or restore defect resets the soak gate. Test rendering and copied-data checks are never reported as physical-device evidence.
